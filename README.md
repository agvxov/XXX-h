# XXX.h

> Analogous function to Perl's '...', named XXX.

`XXX.h` defines the macro `XXX` which is a placeholder for unimplemented code branches.

If execution reaches `XXX`, the program prints a message like Perl's `...` would
(e.g. `Unimplemented at test.c line 5.`)
and aborts.

`XXX` wraps a function of the same name, meaning you can set debugger breakpoints at `XXX`.

`XXX` can be used with or without trailing parenthesis.
